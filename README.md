# JavaScript Notes in English 📘

A complete, beginner-friendly **JavaScript notes series** written in plain English — from your very first `console.log()` to building a full interactive dashboard.

Created by **[Reyrove](https://reyrove.github.io/)** ☕💻

---

## 📖 About This Repo

This repository contains **24 structured sessions** covering JavaScript from absolute zero to building real, working apps. Each session is written in a casual, easy-to-follow style — no jargon walls, no boring textbook vibes.

Whether you're a total beginner or brushing up on the fundamentals, these notes are designed to be read, practiced, and revisited.

## 🚀 What You'll Learn

By the end of these notes, you'll be comfortable with:

- ✅ Writing and running JavaScript in the browser
- ✅ Variables, constants, and all core data types
- ✅ Operators, type conversion, and string/number manipulation
- ✅ Arrays and objects (storing and manipulating data)
- ✅ Conditionals (`if/else`, `switch`) and loops
- ✅ Functions — declarations, expressions, and arrow functions
- ✅ Scope and hoisting (the stuff that confuses everyone)
- ✅ DOM manipulation and event handling
- ✅ Form validation
- ✅ Building a real To-Do List app
- ✅ Persisting data with `localStorage` and JSON
- ✅ Modern ES6+ syntax
- ✅ Debugging like a pro

## 🛠️ How to Use These Notes

1. **Clone or download** this repository
2. Open `index.html` in your browser — the notes are all there, organized by session
3. Use the **jump menu** on the left to navigate between sessions
4. Open your **browser console** (`F12`) to try the code examples live
5. Practice — don't just read. Type out the examples yourself

## 💻 Running Locally

No build tools, no dependencies. Just open the file:
